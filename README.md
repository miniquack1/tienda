# Arauco Importaciones - Tienda de Herramientas

Tienda web estática para mostrar, buscar y gestionar un catálogo de herramientas y equipos industriales.

Proyecto creado para programación web como parte de mi ruta de aprendizaje

La aplicación incluye una página principal, catálogo de productos, carrito de compras, página de contacto y un panel administrativo protegido por contraseña.

## Características

- Catálogo dinámico obtenido desde una API REST.
- Búsqueda de productos por nombre, código o categoría.
- Filtrado por categorías.
- Vista de tienda en cuadrícula o lista.
- Carrito de compras con control de cantidades.
- Flujo de entrega y pago dentro del carrito.
- Consultas directas mediante WhatsApp.
- Página con información de contacto y horarios.
- Panel CRUD para crear, consultar, editar y eliminar productos.
- Diseño adaptable para dispositivos móviles.

## Páginas

| Archivo | Descripción |
|---|---|
| `index.html` | Página principal, tienda, carrito y navegación. |
| `admin.html` | Panel administrativo para gestionar el catálogo. |
| `contacto.html` | Información de contacto y formulario de consulta por WhatsApp. |

## Tecnologías

- HTML5
- CSS3
- JavaScript
- MockAPI
- Google Fonts
- WhatsApp

No utiliza frameworks ni requiere un proceso de compilación.
